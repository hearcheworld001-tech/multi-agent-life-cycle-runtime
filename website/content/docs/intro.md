# 文档版本说明

本网站使用 Docusaurus 的原生文档版本功能。

- **最新设计**：持续更新中的设计文档，代表下一阶段的工作基线。
- **1.0（冻结）**：第一份可对外阅读的稳定设计快照；正文不会随最新版本直接改写。

当一次设计迭代满足冻结条件后，执行：

```bash
npm run docusaurus docs:version 1.1
```

这会将当时的 current 文档复制到 `versioned_docs/version-1.1/`，并生成对应侧边栏配置。随后继续修改 `content/docs/`，不会影响已冻结版本。

版本号用于读者理解和变更治理；Git Tag 用于精确锁定源码提交。建议每次冻结文档版本后创建同名 Tag，例如 `docs-v1.0.0`。

## 阅读入口

1. [总体概览](./guide/overview.md)：建立问题边界和共同语言。
2. [核心契约](./guide/contracts.md)：查看后续实现必须满足的约束。
3. [工程路线图](./guide/roadmap.md)：了解阶段目标和退出标准。

:::tip 版本切换
页面顶部的版本菜单可在“最新设计”和“1.0（冻结）”之间切换。若某篇页面在旧版本不存在，菜单会自动回到该版本的首页。
:::
