# 记忆架构

记忆不是上下文的无限堆积，而是一个可检索、可更新、可遗忘的生命周期：

```text
Experience -> Evaluation -> Encoding -> Storage
           -> Retrieval -> Usage -> Update / Forget
```

| 层级 | 作用 |
| --- | --- |
| Working Memory | 当前任务和短期推理空间 |
| Episodic Memory | 事件、过程、结果和评价 |
| Semantic Memory | 从经历中抽取的知识与规律 |
| Procedural Memory | 已验证的技能、流程和策略 |
| Self Memory | 能力表现、失败模式和成长历史 |

检索应由当前情境、相关性和重要性触发。遗忘和降权用于控制资源，并保留真正影响未来决策的经验。
